# Rules coverage

What the engine (`shared/engine`) enforces, where it deviates from the published rules, and the
test that checks it. "Variation" means a lobby setting (Variations, at the top of the room settings).

## Christmas Candy

Christmas Candy is a room setting (`christmasCandy`) on top of the Christmas look: candy tiles,
cards, and icons, and candy names for the five resources (Candy Cane, Twizzler, Cotton, Gum Drop,
Kiss; `shared/candy-names.ts`). The lobby's one "Art style" choice sets the look: Normal,
Christmas, or Christmas Candy. Either Christmas choice brings Christmas pieces and the North Pole
(Santa); Christmas Candy also sets `christmas`. Settings: `santa.test.ts`; lobby, game table,
and phone: `christmas-ui.spec.ts`, `candy-game.spec.ts`, `phone.spec.ts`.

**Candy trains** (our own rule). The board editor's Train tool draws up to four tracks per layout
along land corners; the first corner is the start station. Rails run beside the edges on one side,
always the land side (`railSideIsLand` in `maps/candy-train.ts`, `candy-train.test.ts`). Each track's number is drawn each game
from the two rolls with the dots set in the editor (default three dots: a 4 or a 10; `trainNumber`
in `maps/candy-train.ts`). Room setting "Candy train" (`candyTrains`, on by default,
shown with Christmas Candy) plays with the train; on a map without tracks (the standard island
included) each game lays one: a snaking track past about 12% of the corners and bordering about 2/5 of the land tiles
(`TUNING` in `shared/default-settings.ts`), its rails on the land
side of every edge, split into legs on separate islands on a sea map (`maps/auto-train.ts`,
`auto-train.test.ts`). The train comes out of a tunnel, always drives forward, and goes into a
tunnel at the end of each leg, coming out of the same-colored tunnel at the next leg's start; picks
run through every leg in order.

| Rule            | How it plays                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Code / tests                                                                      |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| Loading         | When the train's number is rolled, it is loaded from the bank with one random standard card per pick plus 2 spares                                                                                                                                                                                                                                                                                                                                           | `engine/candy.ts`, `candy-engine.test.ts`                                         |
| Picks           | Each settlement on the track picks one card, each city two, in track order from the start station, on the short-choice clock (a bot picks for anyone out of time). A player whose picks come in a row (a city, or the next building's with no one else's pick between) chooses them all and takes them together; another player's pick between ends the run                                                                                                  | same                                                                              |
| Leftovers       | Cards still on the train go back to the bank                                                                                                                                                                                                                                                                                                                                                                                                                 | same                                                                              |
| Order in a turn | Gold choices, then volcano dice, then the candy train, then Santa                                                                                                                                                                                                                                                                                                                                                                                            | `afterEruption` in `engine/turn.ts`; `candy-engine.test.ts`, `candy-game.spec.ts` |
